# 软件依赖迁移工作台

第一版使用 Go 实现依赖求解与独立核验，React 提供操作页面。输入为本地虚构版本资料，后续真实包管理器格式可在 HTTP 层之外新增适配器，统一转换成内部 Manifest。

## 能力

- 选择一个组件和目标版本后，求解必须一起调整的组件。
- 先搜索满足所有非可选依赖约束的方案，再比较组件改动数量。
- 改动数量相同时选择最低可行版本，不默认追最新版本。
- 支持锁定部分组件版本并重新求解。
- 支持部分采纳方案：已确认组件可通过 `confirmed`（或现有 `locks`）固定，求解器继续为剩余迁移目标寻找兼容组合。
- 独立核验逐项输出迁移目标状态：`satisfied`、`pending`、`unmet`，空选择或未提供目标都不能证明覆盖成功。
- 冲突报告包含依赖链，定位哪个组件版本要求了不兼容版本。
- 可选依赖无法满足时允许省略并给出警告；循环依赖作为独立检查警告。
- 保存方案后调用独立 verifier 重新核验，页面可再次调用核验接口比较结论。

## 分阶段升级路线

- 路线由一系列可独立执行的步骤组成；每个中间状态都通过独立 verifier 核验，空选择不能充当覆盖证明。
- 单步不允许跨多个大版本，必要时会安排过渡版本，并说明为何需要以及哪些组件必须一起切换（相互依赖时单独切换没有可行中间状态）。
- 每个计划步骤附带执行后应完成的核对（启动健康、跨大版本的一次性数据迁移、组件退出备份）；用户逐项记录成功、失败或资料不足。
- 只有全部核对记录为成功的已执行步骤才算完成：计划中写着某步、或核对资料不足，都不会把该步当成已生效，后续路线从真实已完成状态继续。
- 核对失败且步骤含不可直接撤回的转换时，报告三种选择并分别列出仍未解决的影响：保留当前状态修正后续路线、回到仍兼容的旧状态（仅恢复版本选择，数据转换不撤销）、停止处理。
- 确认前几步后可以修改最终目标或锁定尚未升级的组件；后续规划只从已完成状态继续，已执行的转换与核对记录保持原样，不会被新路线覆盖或重算。
- 某一步无法继续时，报告可回退到的兼容状态与不可直接撤回的影响（可选组件退出、跨大版本数据迁移）；找不到路线时列出剩余冲突。
- 路线可保存到 routes.json（ROUTES_PATH 覆盖）；确认接口幂等，保存中断后重试不会重复执行一次性转换，重开后每个中间状态、核对依据与剩余冲突都能独立解释，资料不足的步骤保持待确认。

## 运行

在仓库根目录执行：

1. npm install
2. npm run build --prefix frontend
3. go run ./cmd/server

然后打开 http://localhost:8080。

开发模式可分别运行 go run ./cmd/server 和 npm run dev --prefix frontend。

## API

- GET /api/scenarios：列出内置资料（常规升级、循环依赖、锁定版本冲突、不存在候选）。
  另有分阶段路线资料：相互依赖升级、过渡版本、可选组件退出、中途改变目标。
- GET /api/sample?id=base：获取指定资料的完整求解请求。
- POST /api/solve：求解迁移方案，冲突时返回从升级请求/锁定出发的完整依赖链。
- POST /api/plans：保存方案；服务端冻结请求中的 manifest 快照，并调用独立 verifier 重新核验，返回 consistent 结论，不采信求解阶段标记。
- POST /api/plans/verify：对完整迁移请求（manifest、目标、目标版本/目标列表、确认组件）与选择执行独立核验。
- GET /api/plans：查看已保存方案（含快照与独立核验报告）。
- POST /api/route/plan：规划分阶段路线；请求中的 confirmed 步骤原样保留，仅从已完成状态继续规划剩余步骤。
- POST /api/routes：保存路线（冻结请求与每步独立核验结论）；GET /api/routes 查看已保存路线。
- POST /api/routes/{id}/confirm：记录某步的核对结果（成功/失败/资料不足），从真实已完成状态重算剩余路线；同一一步重复确认不会覆盖已有记录或重复执行一次性转换。可在请求中同时修改尚未执行部分的目标或锁定。

保存后即使修改页面上的约束，旧方案仍保留保存时的 manifest 副本、版本选择和核验结论；可在页面上对同一批方案使用不同锁定进行并排对比。

计划文件默认写入工作目录的 plans.json（PLANS_PATH 覆盖），路线文件为 routes.json（ROUTES_PATH 覆盖）；监听地址用 ADDR（默认 :8080）。
